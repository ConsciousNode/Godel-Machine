## Fixes

### P1. Well-formed programs only (audit finding 1)

- Define **well-formed** in `ISA.md`: every register operand field of every instruction is in 0..15, every opcode is in 0..22, and every branch or call target is an integer.
- `checkCertificate` rejects with a new code, `ill_formed_program`, if the active program **or** the replacement is not well-formed. Add the code to `PROOFS.md` §6 and to the theorem in §1 (the theorem quantifies over well-formed programs).
- `Machine` refuses to load an ill-formed program through **every** path (constructor, `setSolver`, `setSearcher`, `setExam`, `importState`), with a clear error.
- Document in `ISA.md` what the VM does with an ill-formed program if one is run anyway (for example, via `runVM` directly).

### P2. Disclose the seeding (audit finding 2)

- In `REPORT.md`, state plainly that the seed searcher contains identity operations (`MUL r0, r0, r14`; `ADD r0, r0, r13`; `DIV r1, r1, r14`), and that the UI presets `dot` and `norm` contain `÷1` and `−0`. Say why they're there.
- Add a second searcher preset, **`plain`**: the seed searcher with those three lines removed and nothing else changed. Test 6 runs on both searchers and reports both results. Do not require a self-rewrite on either; report what happens.

### P3. Budgets in the theorem (audit finding 3)

In `PROOFS.md` §1, state the budgeted form honestly. On every input where the old program finishes within budget, the new program produces the same outputs at no greater cost. The new program can only finish in cases where the old one ran out of budget, never the reverse.

### P4. Canonical certificates (audit finding 4)

Witness fields a rule does not use must be `0`. Otherwise reject with `noncanonical_certificate`. Document which fields each rule uses.

### P5. Browser test

If no browser driver is available, Test 9 prints `SKIPPED: <reason>`, and the summary reports passed / failed / skipped. A skip is never a pass. Accept Selenium or Playwright.

## Tests to add

1. **Ill-formed rejection.** For each of the 14 rules, a certificate on a program with an out-of-range register field is rejected with `ill_formed_program`. Each load path refuses ill-formed programs.
2. **Positive control.** A machine option, `allowIllFormed: true` (default false), turns the P1 check off. With it on, the auditor's two UNSOUND probes must be accepted again, and your test 1 must fail. That proves the test can see the bug.
